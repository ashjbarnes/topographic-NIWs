# topographic-NIWs

This repository hosts the material for the manuscript

> Barnes, A. J., Shakespeare, C. J., Hogg, A. McC., and Constantinou, N. C., Rapid topographic scatter of near-inertial waves generated by storms. _Journal of Physical Oceanography_, **55(10)**, 1847-1858. doi:[10.1175/JPO-D-24-0240.1](https://doi.org/10.1175/JPO-D-24-0240.1)

The folder 'generate expts' contains python notebooks used to set up and run instances of GFDL's MOM6 ocean model. The folder of analysis notebooks contains the code used to produce all of the figures. The other python files in the main directory contain libraries of analysis, model setup, postprocessing and data cataloguing functions.
